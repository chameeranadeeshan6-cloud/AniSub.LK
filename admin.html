How to add a subtitle

  1. Upload a subtitle file you own or have permission to distribute.
  2. Copy its file path from the repository.
  3. Edit data.json and enter that path in the episode's file field.
  4. Change subtitle to an appropriate status, such as Available.
  5. Commit the changes and wait for GitHub Pages to update.

Important security note

This is a static admin helper, not a password-protected admin application. Do not add passwords, personal tokens, or API keys to these files. Keep your GitHub account private and enable two-factor authentication if available. Do not upload anime episodes or subtitles unless you have distribution permission.
